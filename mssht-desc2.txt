Below is a complete systems-level description of the major modules, features, and functionality to be added.

---

# 1. CLASS MANAGEMENT MODULE

## Purpose

This module manages the creation and administration of virtual classrooms.

---

## Features

### 1.1 Class Creation

Teachers can:

* Create unlimited classes
* Assign class names
* Add sections and subjects
* Define room numbers
* Customize themes and banners

### Functionality

* Automatically generates class codes
* Creates dedicated Google Drive folders
* Creates linked Google Calendar entries

---

### 1.2 Class Enrollment

#### Methods

* Join code
* Email invitation
* Domain-based enrollment
* SIS integration 

### Functionality

Students can:

* Self-enroll using codes
* Accept invitations
* Access all class resources immediately

---

### 1.3 Multiple Teacher Support

Allows:

* Primary teacher
* Co-teachers
* Teaching assistants

### Permissions

Co-teachers can:

* Create assignments
* Grade work
* Post announcements
* Manage discussions

---

### 1.4 Class Archiving

At the end of a term:

* Classes can be archived
* Data remains accessible
* Prevents accidental edits

---
